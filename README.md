# Uninstall+

一个极致轻量、纯 Kotlin 原生的 Android 端应用卸载与管理增强小工具。由极客独立打造，坚持纯粹极简路线，向市面上那些臃肿、满是广告和牛皮癣的软件宣战。

## 💡 核心特点

- **极致轻量**：安装包仅 200K 左右，真正做到麻雀虽小、五脏俱全。
- **纯粹原生**：全面采用 Kotlin 与 Android 原生 API 手工构建，零第三方库、零第三方依赖。
- **绝对纯净**：零广告、零弹窗、零强制关注、零诱导打赏，回归软件最纯粹本质。
- **匠心彩蛋**：代码中精心埋入了一些极客专属的小彩蛋。
